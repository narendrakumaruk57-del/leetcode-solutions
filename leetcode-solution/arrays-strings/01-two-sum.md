## Problem: Two Sum (Easy)
**Link:** https://leetcode.com/problems/two-sum/

### Approach
Used a nested loop (brute force approach) to check every possible pair of numbers in the array to find which two elements add up to the target value.

### Complexity
- Time: $O(N^2)$
- Space: $O(1)$

Learned how to test array-based logic and handle dynamically allocated memory locally before submitting to the online judge.
