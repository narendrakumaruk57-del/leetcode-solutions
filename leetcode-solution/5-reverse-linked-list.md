## Problem: Reverse Linked List (Easy)
**Link:** https://leetcode.com/problems/reverse-linked-list/

### Approach
Used an iterative approach with three pointers (`prev`, `current`, and `nextTemp`) to reverse the direction of the pointers in a singly-linked list in-place.

### Complexity
- Time: $O(N)$ where $N$ is the number of nodes in the linked list.
- Space: $O(1)$ since pointer updates are done iteratively without extra memory.

### Notes
Mastered pointer manipulation for rearranging nodes in a linked list efficiently.
